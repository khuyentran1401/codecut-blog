# prompt A/B test phantom gains

Scripts, cases, and recorded results for the article:
`articles/prompt-ab-test-phantom-gains-results-first.qmd`.

## What was run

100 BFCL V4 tool-calling cases against
`deepseek/deepseek-v4-flash-0731` through OpenRouter.

Two prompt checks were recorded:

- **Provider sweep**: Prompt A pinned to six providers, three runs per provider.
- **Pinned prompt A/B**: Prompt A vs. Prompt B pinned to `deepinfra/fp8`, three runs per prompt.

Every request used `temperature=0`, `top_p=1`, and `max_tokens=1024`.

## Run

To print the article tables from the recorded `results.jsonl`:

```bash
scripts/run_prompt_ab_eval.sh
```

To rerun the API experiment from scratch, set `OPENROUTER_API_KEY` in the repo
root `.env`, then run:

```bash
scripts/run_prompt_ab_eval.sh --rerun
```

The full rerun issues 2,100 requests:

- 1,800 provider-sweep requests
- 300 pinned prompt-comparison requests

## Outputs

`scripts/analyze.py` prints:

- provider scores across three pinned runs
- Prompt A vs. Prompt B scores on `deepinfra/fp8`

## Files

| Path | Contents |
| --- | --- |
