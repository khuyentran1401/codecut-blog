---
name: commit-message
description: Writes a git commit message from a description of a change.
---

Write the commit message as a single line, in the form `type(scope): description`.

## Examples

**Example 1**

```text
fix(csv): skip rows with no delimiters
```

**Example 2**

```text
feat(api): add rate limit headers
```

**Example 3**

```text
chore(deps): bump ruff to 0.14
```

**Example 4**

```text
docs(readme): fix broken install link
```
